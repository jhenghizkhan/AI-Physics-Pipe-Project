# AI Physics Pipe Project 
This project simulates standing waves in open and closed pipes using Python. 
Students can type or speak commands to control harmonic, pipe type, and length. 
 
## How to Run Locally 
1. Clone the repo: git clone https://github.com/jhenghizkhan/AI-Physics-Pipe-Project.git 
2. Install dependencies: pip install -r requirements.txt 
3. Run the main program: python step7_pipe_ai_loop.py 
 
## Notes 
- Voice input works only when running locally in Python. 
- Typed commands work both locally and in Binder.
